# Success Express Service Sales Performance Dashboard (Power BI)
# Project Overview
This project analyzes service sales data for Success Express from December 2021 to September 2023 to evaluate business performance across services, locations, and time periods using Microsoft Power BI.
The objective was to transform raw sales data into an interactive dashboard that supports data-driven decision-making and provides insights into revenue trends, top-performing services, and regional performance.
# Project Objectives
• Analyze overall service sales performance
• Identify top-performing services by revenue
• Examine revenue distribution across locations
• Evaluate monthly sales trends over time
• Identify growth opportunities and underperforming areas
• Support strategic planning through data-driven insights
# Tools Used
• Microsoft Power BI
• Power Query
• DAX (Data Analysis Expressions)
• Microsoft Excel
# Dashboard Features
• KPI Cards (Total Revenue, Number of Services, Top Service, Top Location)
• Service revenue comparison chart
• Location-based revenue performance analysis
• Monthly sales trend visualization
• Revenue share distribution by service category
• Interactive filters for time and service selection
• Detailed data table for drill-down analysis
# Key Insights
• Express Parcel generated the highest revenue among all services.
• Logistics Support and Warehousing are also major contributors to overall revenue.
• Revenue performance varies significantly across locations.
• Ibadan, Kano, and Lagos are among the highest revenue-generating regions.
• Monthly sales trends show fluctuations, indicating seasonal demand patterns.
